# AI IT Helpdesk & Knowledge Copilot

An AI-powered internal IT helpdesk assistant built using a project-based learning approach.

## Project Objective

The system will eventually be able to:

- Answer company knowledge questions using RAG
- Decide when retrieval or another action is required
- Perform actions using tools
- Orchestrate workflows using LangGraph
- Access tools through MCP
- Expose functionality through an API
- Handle errors and log important events
- Include tests and documentation

## Learning Path

RAG → Agentic AI → LangGraph → MCP

## Learning Method

Learn → Implement → Test → Understand → Modify → Debug
